# 💱 Currency Converter

A modern and responsive Currency Converter Web Application built using HTML, CSS, and JavaScript. This application provides real-time currency conversion with live exchange rates and dynamic country flag updates, offering a smooth and user-friendly experience.

## ⚙️ How It Works

1. Enter the amount to convert.
2. Select the source currency.
3. Select the target currency.
4. Click on "Get Exchange Rate".
5. The application fetches real-time exchange rates from the API.
6. The converted amount is displayed instantly.
